# configs

NEXUS generates its runtime configuration automatically at
`~/.nexus/config.json` (created by `nexus up master|block`).

You normally do **not** edit files here. This directory is for optional,
version-controlled example configurations.

- `master.example.json` — shape of a MASTER config (no secrets).
- `block.example.json` — shape of a BLOCK config (no secrets).
